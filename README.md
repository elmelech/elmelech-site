# roey.elmelech.com

Static personal site. No build step — plain HTML + CSS.

## Files
- `index.html` — home
- `resume.html` — experience & education
- `contact.html` — contact
- `style.css` — shared styles
- `favicon.svg`, `headshot.jpg` — assets
- `*_archived.html` — retired pages, not linked in nav

## Deploy (GitHub Pages)
1. Push these files to the repo root of a branch (e.g. `main`).
2. Settings → Pages → Source: Deploy from branch → `main` / `root`.
3. Add a `CNAME` file containing your domain if using a custom domain.
